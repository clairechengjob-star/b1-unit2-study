Passiv 被动语态：从“完全不懂”到“看到题就会做”

先只记一句：谁做的不重要，重要的是“某事被做了” → 用被动。

📘 本页把你 B1.1 Unit 2 里出现的 wird geprobt / werden frisiert / wird kontrolliert / wurde gefeiert 作为教材核心例子；后面“状态被动、情态动词被动、Perfekt”标为扩展，方便你以后做 B1 题。

① 什么是被动？先用中文理解

主动 Aktiv

化妆师给演员化妆。

重点：谁做这件事？→ 化妆师。

Die Maskenbildnerin schminkt den Schauspieler.

被动 Passiv

演员被化妆。

重点：演员发生了什么？→ 被化妆。

Der Schauspieler wird geschminkt.

小白判断法：中文里如果能自然出现“被……、会被……、正在被……”，德语里就很可能要考虑 Passiv。
但是：德语被动不是简单加一个“被”字。真正要做的是：werden 变位 + Partizip II。

② Passiv Präsens 怎么造？只记这条公式

werden（变位） + Partizip II（过去分词）
主语werden 现在时例子
ichwerdeIch werde gefragt.
duwirstDu wirst gefragt.
er/sie/eswirdDas Bühnenbild wird kontrolliert.
wirwerdenWir werden gefragt.
ihrwerdetIhr werdet gefragt.
sie/SiewerdenDie Schauspieler werden geschminkt.

主动句 → 被动句，四步法

1
先找主动句的第四格宾语。
Die Maskenbildnerin schminkt den Schauspieler.
2
把这个第四格宾语变成被动句主语。
den Schauspieler → der Schauspieler
3
根据新主语选 wird / werden。
der Schauspieler 是单数 → wird
4
原动词变 Partizip II，放句末。
schminken → geschminkt
Der Schauspieler wird geschminkt.
谁做的可以不说。如果要说，用 von + Dativ：
Der Schauspieler wird von der Maskenbildnerin geschminkt.

③ 被动的时态：先会 Präsens，再认 Präteritum

时态结构例句中文
Präsenswird/werden + Partizip IIDie Tür wird geöffnet.门正在/会被打开。
Präteritumwurde/wurden + Partizip IIEs wurde gefeiert.当时在庆祝。
Perfekt*ist/sind + Partizip II + wordenDie Tür ist geöffnet worden.门已经被打开了。
Modalverb*Modalverb + Partizip II + werdenDie Tür muss geöffnet werden.门必须被打开。

* 这两项属于扩展，不是你 Unit 2 当前最核心的第一页要求；先保证 Präsens / Präteritum 会做。

最容易混：wird vs wurde

wird / werden
现在、一般情况

Heute wird das Bühnenbild kontrolliert.
今天舞台布景会被检查。
wurde / wurden
过去发生

Gestern wurde das Bühnenbild kontrolliert.
昨天舞台布景被检查了。

④ 你 Unit 2 里的被动原句，一句句看懂

1. Während Sie sich auf die neue Spielzeit freuen, wird hier fleißig geprobt, gebaut, genäht, gemalt, frisiert, installiert.
🇨🇳 当您期待新演出季时，这里正在勤奋地排练、搭建、缝制、绘画、做发型、安装设备。

👶 教材核心：无人称/省略施事者的过程被动。wird + 多个 Partizip II。

2. Vor jeder Aufführung werden die Schauspielerinnen und Schauspieler frisiert.
🇨🇳 每次演出前，演员们都会被做发型。

👶 教材练习：复数主语，所以用 werden。

3. Viele Kleidungsstücke werden für die Produktionen repariert.
🇨🇳 许多服装会为了演出制作而被修理。

👶 教材练习：主动宾语 Kleidungsstücke 变成被动主语。

4. Vor jeder Aufführung wird das Bühnenbild kontrolliert.
🇨🇳 每次演出前，舞台布景都会被检查。

👶 教材练习：das Bühnenbild 单数，所以用 wird。

5. Die Kulissen werden nach den Ideen der Regisseurinnen und Regisseure vorbereitet.
🇨🇳 布景会按照导演们的想法准备。

👶 教材练习：vorbereiten → vorbereitet；被动中 Partizip II 放句末。

6. Heute wird die Mode aus dem frühen 20. Jahrhundert recherchiert.
🇨🇳 今天会研究20世纪初的时尚。

👶 教材练习：recherchieren 是 -ieren 动词，Partizip II = recherchiert，不加 ge-。

7. Jeden Tag werden die Schauspielerinnen und Schauspieler geschminkt.
🇨🇳 每天演员们都会被化妆。

👶 教材练习：复数主语 → werden；schminken → geschminkt。

8. Während noch gefeiert wurde, hat meine Mutter meine kleine Schwester nach Hause gebracht.
🇨🇳 聚会还在继续时，我妈妈把妹妹带回家了。

👶 教材中出现的过去时被动：wurde gefeiert。

⑤ 小白最容易错的 6 个坑

坑1：把 werden 写成“被”的固定词

werden 必须跟着主语变：
das Bühnenbild → wird
die Schauspieler → werden

坑2：句末写原形

❌ Die Schauspieler werden schminken.
✅ Die Schauspieler werden geschminkt.

坑3：-ieren 动词乱加 ge-

recherchieren → recherchiert ✅
不是 gerecherchiert ❌

坑4：可分动词 Partizip II 写错

vorbereiten → vorbereitet
Die Kulissen werden vorbereitet.

坑5：主动宾语变主语，格要跟着变

Aktiv: Die Maskenbildnerin schminkt den Schauspieler.
Passiv: Der Schauspieler wird geschminkt.

坑6：过程被动 vs 状态被动

werden + Partizip II
动作正在发生：
Die Tür wird geöffnet.
门被打开。
sein + Partizip II
结果状态：
Die Tür ist geöffnet.
门是开着的。

⑥ 一眼做题法：考试只走这 5 步

1
先判断：题目要表达“谁做”还是“某事被做”？
2
如果是被动，先写 werden 的正确形式。
3
看主语单复数：单数多用 wird，复数 werden。
4
把动作动词变成 Partizip II。
5
Partizip II 放句末，再检查 -ieren / 可分动词。
主语 + wird/werden + …… + Partizip II
