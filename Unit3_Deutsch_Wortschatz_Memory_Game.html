疑问句
无疑问词：动词第1位。
有疑问词：疑问词 + 动词第2位。
Perfekt
haben/sein 第2位，Partizip II 放句末：

可分动词
词干第2位，前缀句末：
Er meldet sich an.
情态动词
情态动词第2位，原形句末：
Man kann helfen.
dass / weil 从句
从句里的变位动词放最后：
…, dass er kommt.
